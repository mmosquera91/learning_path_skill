    **Context for the executor:** These SQL blocks are NOT executed directly by Python code. They are Markdown-embedded SQL that the LLM reads and then executes via the Hermes Agent's `execute_code` or `terminal` tool. The LLM sees the SQL, understands the `?` parameter, and is expected to bind the user input properly when constructing the actual Python/SQLite call. The ESCAPE clause documents the escaping requirement so the LLM knows to handle `%` and `_` in user input.

    **Why this works in the Hermes context:** The LLM constructs a Python script using `sqlite3` when it encounters SQL in a subskill. By writing `LIKE ? ESCAPE '\'` in the Markdown, the LLM will generate `cursor.execute("... LIKE ? ESCAPE '\\'", ('%' + escaped_topic + '%',))` instead of f-string interpolation.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user->eval.md->DB | User submission text flows through LLM evaluation into SQLite response column |
| user->SKILL.md->DB | User topic string used in LIKE search query |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Injection | SKILL.md LIKE clause | mitigate | Parameterized LIKE with ESCAPE clause (FIX-04). LLM binds user input as parameter instead of string interpolation. Prevents SQL metacharacter manipulation. |
| T-03-02 | Injection | adapt.md LIKE clause | mitigate | Same parameterized LIKE with ESCAPE clause (FIX-04). |
| T-03-03 | Tampering | DB file permissions | mitigate | chmod 600 on creation (SEC-02). Prevents other users on shared system from reading/writing the DB. |
| T-03-04 | DoS | Oversized response | mitigate | CHECK constraint on response length (SEC-01). 10000 char limit prevents DB bloat from extremely long submissions. |
| T-03-05 | Spoofing | User input in LLM-generated SQL | accept | The LLM is the SQL executor, not the user. User input passes through the LLM which constructs the actual Python/SQLite call. The parameterized pattern is defense-in-depth -- even if the LLM faithfully interpolates, the ESCAPE clause prevents metacharacter abuse. |
</threat_model>
