## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer->DB | Developer runs migration manually; migration SQL runs with full permissions |
| init_db.py->SQLite | Script creates DB with no prior auth; depends on filesystem permissions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | migrate_db.py backup | accept | Single-user machine, single developer. Backup is local file copy. No remote attacker. |
| T-01-02 | DoS | Down-migration data loss | mitigate | Backup created before down-migration (per D-02). User can restore from .bak file if data loss occurs. Document backup location in script output. |
| T-01-03 | Information Disclosure | Backup files (.bak.vN) | accept | Backup files inherit filesystem permissions from parent directory. Single-user machine -- no cross-user risk. Backups deleted manually after verification. |
</threat_model>
