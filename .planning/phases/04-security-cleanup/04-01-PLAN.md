Run in the repo root (`/home/server/.hermes/skills/tutor`):

```bash

```

If the stash is empty (no changes), skip to Step 2.


## STEP 2 — Switch to master and merge gsd-experiment

```bash
git merge gsd-experiment --no-edit
```

Expected: Fast-forward or merge commit created. Abort if there are conflicts (should not happen).


## STEP 3 — Verify merge success

```bash

```

Confirm the latest commit is the most recent one from gsd-experiment.


## STEP 4 — Create full bundle backup OUTSIDE the repo directory

```bash

```

Verify the bundle was created:

```bash

```

## STEP 5 — Run git filter-repo to purge learning.db from ALL history

```bash
git filter-repo --path learning.db --invert-paths --force
```

This rewrites ALL branches (local master, local gsd-experiment, all remote branches) in one pass.
The `--force` flag is required because the repo was previously cloned (not a fresh clone).
Expected output: reports number of commits rewritten, number of refs updated.


## STEP 6 — Verify purge success (CRITICAL — must both pass)

**Check 1 — No file was ever added:**
```bash
git log --all --diff-filter=A -- learning.db
```
Expected: no output (no results).

**Check 2 — No blob contains the string "learning.db":**
```bash
git rev-list --all | xargs git grep -l 'learning.db' 2>/dev/null
```
Expected: no output (no blob contains the string).

If either check returns results, STOP and report failure.


## STEP 7 — Force-push ALL rewritten branches to origin

```bash
git push --force --all origin
```

This updates all remote branches to their rewritten counterparts.


## STEP 8 — Force-push all tags to origin

```bash
git push --force --tags origin
```

This ensures no tag references old history with the blob.


## STEP 9 — Run local garbage collection to prune dangling objects

```bash
git gc --prune=now
```


## STEP 10 — Return to gsd-experiment and restore stashed changes

```bash
git checkout gsd-experiment
git stash pop
```

Verify the stash was popped (no remaining stash entries).
