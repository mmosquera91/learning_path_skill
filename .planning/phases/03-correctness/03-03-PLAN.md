## Parameterize error messages in daily.md

**Background:** daily.md Steps 6, 7, 8 contain hardcoded Spanish error messages. These need to be parameterized so the SKILL.md persona (now reading locale from config) can generate the appropriate language.

**Steps to fix:**

### Step 6 (LLM task generation failure) - around line 89
**Before:**
"No pude generar la tarea. Intenta de nuevo mas tarde."

**After:**
"Based on user's locale (config table: SELECT value FROM config WHERE key='locale';), send: Spanish: 'No pude generar la tarea. Intenta de nuevo mas tarde.' English: 'I could not generate the task. Please try again later.'"

Actually, do NOT use Mustache syntax here since this is a prompt file. Instead, use inline instructions to the LLM:

```
On failure, report error to user in their language (check config.locale):
- If locale=es or not set: "No pude generar la tarea. Intenta de nuevo mas tarde."
- If locale=en: "I could not generate the task. Please try again later."
```

### Step 7 (DB write failure) - around line 110
**Before:**
"Error al guardar la tarea. Intenta de nuevo mas tarde."

**After:**
```
On DB error, report to user in their language:
- If locale=es or not set: "Error al guardar la tarea. Intenta de nuevo mas tarde."
- If locale=en: "Failed to save the task. Please try again later."
```

### Step 8 (Telegram delivery failure) - around line 131
**Before:**
"No pude enviar la tarea. Intentare de nuevo manana."

**After:**
```
On Telegram delivery failure, report to user in their language:
- If locale=es or not set: "No pude enviar la tarea. Intentare de nuevo manana."
- If locale=en: "I could not send the task. I will try again tomorrow."
```

**Important:** These are instructions WITHIN a markdown prompt file (daily.md), not Mustache template variables. The LLM executing this subskill should follow these inline instructions to generate the message in the user's language.
